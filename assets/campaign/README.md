# Fresh Fruit Daily — Campaign Assets

Six upload-ready JPEGs and six editable SVGs, matching the previously delivered campaign kit.

- Instagram: 1080 × 1350 RGB JPEG, 4:5.
- Facebook: 1200 × 630 RGB JPEG.
- Editable SVG typography: DejaVu Sans, with Arial/sans-serif fallback. The reusable kit includes the fonts and licence.
- All artwork is illustrative, not actual product photography.
- `manifest.json` records SHA-256 hashes and image sizes.
